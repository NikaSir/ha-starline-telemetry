# iPhone summary target

Approved mobile composition for the first StarLine tab:

1. `130-й` first, `683-й` second.
2. Both vehicles visible in the same scrollable summary.
3. The redundant vehicle selector is hidden on Summary and retained on single-vehicle tabs.
4. Compact hero scene per vehicle with background and vehicle as separate local layers.
5. Four live metrics in one horizontal row at the bottom of the hero: battery, fuel, engine temperature, cabin temperature.
6. Connectivity is a separate floating chip on the right.
7. Perimeter is one compact row: hood, doors, trunk.
8. Operational state is a second compact row: engine, expanded latest event, parking brake.
9. Event width is taken from the handbrake column without increasing the row or card height.
10. At 100% scale the layout targets iPhone portrait density; zoom remains available for accessibility.
11. Header and bottom navigation remain outside the zoomed workspace.

# iPhone summary target

Approved mobile composition for the first StarLine tab:

1. `130-й` first, `683-й` second.
2. Both vehicles visible in the same scrollable summary.
3. Compact hero scene per vehicle with background and vehicle as separate local layers.
4. Four live metrics in one horizontal row at the bottom of the hero: battery, fuel, engine temperature, cabin temperature.
5. Connectivity is a separate floating chip on the right.
6. Perimeter is one compact row: hood, doors, trunk.
7. Operational state is a second compact row: engine, parking brake.
8. Last event is a separate compact row.
9. At 100% scale the layout targets iPhone portrait density; zoom remains available for accessibility.
10. Header and bottom navigation remain outside the zoomed workspace.
